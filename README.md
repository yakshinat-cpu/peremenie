# 🐍 Python с нуля

Игровая статическая образовательная платформа для школьников 10–14 лет.

## Реализовано

- главная страница и навигация;
- первый полноценный урок «Переменные»;
- теория и примеры;
- блок-заглушка для будущего видео;
- задания трёх уровней сложности;
- проверка ответов на JavaScript;
- сохранение прогресса в localStorage;
- адаптивный яркий интерфейс;
- темы курса: переменные, типы данных, линейные, условные и циклические алгоритмы.

## Публикация

Проект не требует сервера и БД. Для GitHub Pages выберите Settings → Pages → Deploy from a branch → main → /(root).

## Хранение прогресса

Прогресс хранится только в браузере ученика через localStorage и не отправляется на сервер.
